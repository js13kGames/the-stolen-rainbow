# The Stolen Rainbow

요일의 요소가 사라진 세계에서 같은 색 탄막을 깨고, 유니콘과 함께 불·물·나무·황금·대지·태양·달을 모으는 게임입니다. 이동 발사원, 감속·재조준, 반사, 다층 공전, 분기, 양날개를 색 파괴와 일곱 공격에 맞춰 구성했습니다.

## 일곱 요소를 되찾는 여정

전투의 중심에는 잃어버린 요소가 봉인되어 있습니다. 화요일 불부터 차례로 되찾으면 왼쪽 수집 목록이 채워집니다. 마지막 월요일의 달까지 모으면 일곱 요소와 무지개가 돌아온 세계를 엔딩으로 보여줍니다.

## 픽셀 표현

320×240 화면을 픽셀 그대로 확대합니다. 요소와 유니콘, 작은 글자를 코드로 만든 픽셀 그림으로 표현하고, 명암·보행·파편을 더했습니다. 전투 배경은 단색이며 공격 예고가 먼저 표시됩니다.

## 전투

각 전투는 월 남색·화 빨강·수 파랑·목 초록·금 노랑·토 주황·일 보라 중에서 해당 요일과 가까운 세 색을 씁니다. 플레이어의 세 무기와 적 탄·발사 예고도 같은 배색을 따릅니다. 화요일은 빨강 확산·노랑 추적·주황 폭발입니다. 같은 색 공격으로 같은 색 탄을 파괴합니다.

| 전투 | 1번 | 2번 | 3번 |
|---|---|---|---|
| 화 / 불 | 빨강 확산 | 노랑 추적 | 주황 폭발 |
| 수 / 물 | 파랑 전방파동 | 남색 관통 | 보라 복귀 |
| 목 / 나무 | 초록 추적 | 노랑 폭발 | 파랑 원형파동 |
| 금 / 황금 | 노랑 관통 | 주황 복귀 | 초록 확산 |
| 토 / 흙 | 주황 폭발 | 빨강 원형파동 | 노랑 전방파동 |
| 일 / 태양 | 보라 복귀 | 남색 확산 | 파랑 추적 |
| 월 / 달 | 남색 원형파동 | 파랑 전방파동 | 보라 관통 |

본 전투는 각각 전개·변형·재공격으로 바뀝니다. 예를 들어 목요일은 두 림과 여섯 나선형 살이 줄어들고, 역회전한 뒤 서로 다른 방향으로 방출됩니다. 토요일은 여러 겹의 날개가 접힌 다음 예고 화살과 마름모 울타리로 바뀝니다.

## 요일과 조작

월=밤의 남색, 화=불의 빨강, 수=물의 파랑, 목=나무의 초록, 금=황금의 노랑, 토=흙의 주황, 일=보라입니다. **화요일 빨강부터 월요일 남색까지 일곱 요일 모두 정식 전투**입니다. 월요일에도 보스 체력·피격·패배·재도전이 적용됩니다.

- 방향키 이동, Shift 정밀 이동. 확산 공격은 Shift를 누르면 확산이 좁아지고 사거리가 늘어납니다.
- **Z**: 선택한 색의 공격. 같은 색으로 연결된 탄열을 연쇄 파괴합니다.
- **C**, 또는 **1/2/3**: 해당 전투의 세 무기를 순환하거나 직접 선택합니다. 이미 발사한 공격의 색·동작은 유지됩니다.
- **X**: 폭탄, 적 탄 소거, 3초 무적. 한 번 누를 때 한 발.
- 타이틀 시작 버튼 또는 Enter를 누르면 4초 조작 안내 후 화요일 전투에 진입합니다. 흰 중심점만 플레이어의 피격 판정입니다. 보스를 쓰러뜨린 뒤 Enter로 다음 요일을 진행합니다. 패배 화면의 R은 해당 요일 재도전. 장 완료 시 생명·폭탄 1 회복.
- Esc/P 일시 정지, 정지 중 Q 타이틀, M 음소거. BGM은 없으며 짧은 효과음만 있습니다. SFX ON/OFF 버튼으로 효과음을 전환합니다.

현재 색의 적 탄에는 흰 테두리가 있습니다. 얇은 연결선은 함께 깨지는 관계를 표시하며 피해가 없습니다. 큰 마름모를 부수면 후속 발사가 취소됩니다. 긴 옅은 선은 돌진 예고이며, 예고한 방향은 발사 때 다시 플레이어를 따라 바뀌지 않습니다. 정지·공전 중인 적 탄도 접촉하면 위험합니다. 원형 파동 방어는 무적이 아닙니다.

## 플레이룸·실행

[플레이룸](http://127.0.0.1:8123/qa.html)은 세 탭으로 나뉩니다. **전투**에서는 요일을 고르고 시작합니다. **공격 연습**에서는 무기 궤적과 접어 둔 실전 상황을 확인합니다. **검토 도구**에 구간·예고·프레임 진행·자동 사격을 모았습니다. 화요일 자동 경로 비교는 화요일을 선택했을 때 검토 도구 안에서 펼칠 수 있습니다. 무적은 선택 사항이며 기본 전투는 실제 피격을 적용합니다.

[본편](http://127.0.0.1:8123/index.html), [압축본](http://127.0.0.1:8123/dist/index.html). 로컬 서버가 필요합니다. ZIP을 풀어 최상위 `index.html`을 바로 열어도 됩니다. 키보드가 필요한 Desktop 게임입니다.

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run balance
npm run preview:qa
npm run preview
```

`npm run preview`는 플레이룸을 생성해 둔 경우 플레이룸을, 그렇지 않으면 본편을 엽니다. 플레이룸의 최고점은 본편과 별도로 저장합니다.

이미 8123 서버가 실행 중이면 다시 실행하지 않습니다. `index.html`과 `game.js`가 읽을 수 있는 소스이고, Terser·Roadroller는 빌드 때만 사용합니다. 플레이룸·검사·설계 문서는 제출 ZIP에서 제외됩니다.

## 검증과 빌드 도구

`npm test`는 색 제한·연쇄 파괴·발사 취소·조작·공격 범위·각 전투의 전후반·타이틀과 조작 안내·압축본 실행을 검사합니다. `npm run balance`는 무적 상태의 공격 비교이며 사람의 회피 난이도를 측정하지 않습니다.

Terser와 Roadroller는 빌드 전용 의존성입니다. 각 패키지의 라이선스는 설치된 패키지에 포함되어 있습니다. Roadroller가 생성하는 디코더는 해당 프로젝트의 라이선스 설명에 따라 public domain입니다.

## 대회용 결과물

`npm run build`로 생성하는 `dist/stolen-rainbow-13k.zip`이 플레이용 결과물입니다. ZIP 제한은 13,312바이트이며 초과하면 빌드가 실패합니다. 읽을 수 있는 게임 전체 소스는 `index.html`과 `game.js`, 재현 빌드 설정은 `build.cjs`, `compression.json`, `package.json`, `package-lock.json`입니다. 검사용 도구와 문서는 플레이용 ZIP에 포함되지 않습니다.
